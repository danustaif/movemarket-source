# Desain web 14 Oktober 2026 (landing + papan 3D)

Diekstrak dari bundel `MoveMarket Web Design.html` (ekspor desain, 12 papan). Berkas di sini adalah sumber HTML iframe tiap papan, dapat dibuka langsung di browser lewat server statis lokal (mis. `python3 -m http.server`), dan screenshot acuan.

| Berkas | Isi |
|---|---|
| `landing-desktop.html`, `landing-desktop.png` | Prototype desktop mulai dari landing: hero "Every move is a market." dengan papan catur 3D (three.js, bisa diputar), daftar ply terbaru, pasar "Predict now" di-pin, Next to lock, How results work |
| `landing-mobile.html`, `landing-mobile.png` | Prototype mobile mulai dari landing |
| `components.html` | Komponen, warna, dan state |

Teks UI di implementasi tetap dari `sot/copy.en.json` (aturan 0 dan 9 di `CLAUDE.md`).
