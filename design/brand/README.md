# Brand MoveMarket

| File | Pakai untuk |
|---|---|
| `logo-1024.png` | Logo asli (1024x1024) dari pemilik proyek: avatar organisasi GitHub, profil hackathon |
| `logo.svg` | Logo yang sama sebagai vektor (beda < 0,1% piksel dari PNG, hanya tepi anti-aliasing): favicon web, header, README |
| `mark.svg` | Pion saja, `fill="currentColor"`, untuk latar berwarna |

Warna sama dengan token desain (`DESIGN.md`): gold `#f2c14e` (segitiga kiri atas), coral `#ff8a6b` (kanan bawah), ink `#082a26` (pion).
